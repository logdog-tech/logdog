## 本地文件的处理位置

文件日志由浏览器读取、解码和解析，搜索与文本导出也在本地完成。选择本地文件不需要把日志正文上传到分析服务器。

这不意味着整个页面没有网络请求。在线站点可能加载资源、发送站点统计，账户登录与共享配置也需要与服务端通信。对隔离环境的要求，应通过实际部署和网络策略实现。

## 本地工作区

本地工作区适合个人分析。规则与设置保存在当前浏览器的本地存储中，清除站点数据、切换浏览器或使用隐私模式可能影响这些配置。

不要把浏览器中的配置保存理解为原始日志文件已经持久备份。重新打开页面后，可能需要重新选择本地文件。

## 共享工作区

在线服务的账户和共享工作区能力用于协作管理规则等配置。使用前需要登录并拥有相应工作区权限。

当前开源仓库以静态前端为主。若独立部署后登录或共享不可用，先确认 API 地址与配套服务，不要用本地文件功能能打开来判断后端已经配置完成。

## 离线使用

项目包含 PWA 缓存配置。生产站点首次成功加载相关资源后，可以在缓存可用的条件下离线打开部分功能。首次访问、尚未缓存的资源、登录和共享操作仍可能依赖网络。

发现页面行为与刚部署的版本不一致时，可先检查服务工作线程及浏览器缓存，详见[常见问题](#/troubleshooting)。
