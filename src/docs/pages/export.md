## 选择日志行

| 操作 | 行为 |
| --- | --- |
| 点击行内容 | 选择当前行 |
| Shift + 点击 | 从该视图中的选择起点扩展连续范围 |
| Ctrl / Cmd + 点击 | 增加或取消单行选择 |
| Ctrl / Cmd + A | 全选当前操作视图中的日志 |

先点击目标视图中的一行，再使用全选快捷键。完整日志与搜索结果各自维护选择；搜索输入框中的全选仍是普通文字全选。

## 复制与 1000 行限制

选中日志后按 Ctrl+C（Windows / Linux）或 Cmd+C（macOS），也可以在已选区域内右键选择复制。

**最多 1000 行可以使用行复制。超过 1000 行时请导出为文件。** 快捷键复制会给出提示，右键菜单中的复制项会禁用。

如果存在浏览器原生的文字选区，复制快捷键优先按普通文字复制处理。想复制行选择时，先取消文字选区。

## 导出为文本

在已选中的行上右键，选择「导出选中日志」。浏览器会下载 UTF-8 文本文件，文件名包含导出时间。行按对应视图的顺序输出。

导出的是日志文本，不包括界面配色、行号栏或标记。自定义函数用于显示处理，不应依赖它改写导出的原始日志。

> 右键点击未选中的行会把该行作为新的选择。要保留当前多选范围，请在选区内打开菜单。

## 导出两个搜索结果之间的上下文

例如，搜索结果只有原始第 2000 行与第 3000 行。全选搜索结果会导出这两条记录；第 2001–2999 行没有在结果列表中，因此不在导出范围内。

需要完整上下文时，在完整日志视图中选择第 2000–3000 行，然后从该视图导出。包含两端时，这一范围共 1001 行，应使用文件导出。

## 大范围导出

导出需要读取所选行并生成文件。选择越多、单行越长，耗时与内存开销就越大。在下载完成前保留当前页面，并避免同时修改搜索条件或重新加载数据。
