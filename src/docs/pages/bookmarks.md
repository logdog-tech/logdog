## 标记与选择的区别

标记用于保留值得关注的日志；选择用于本次复制和导出。点击行号切换标记，点击行内容进行选择。两种状态可以同时存在。

通过「只显示标记」把关键事件汇集起来，或使用「显示标记和搜索」在搜索过程中持续保留这些记录。

## 临时文本高亮

选中日志内容中的文字，会出现颜色选择面板。给请求 ID、线程名或模块名分配颜色，可以更容易地区分交错的日志。

临时文字染色属于当前页面会话。需要重复使用的规则，应保存在侧栏的颜色规则中。

## 颜色规则

在侧栏切换到「颜色」，添加规则，填写匹配表达式并选择颜色。规则需要处于启用状态才会参与渲染。

```regex
ERROR|FATAL|panic
```

一种实用的分工是：错误用红色，告警用琥珀色，请求 ID 使用另一种较淡的颜色。不要同时给太多普通词着色，否则重要信息会失去对比。

## 多条规则叠加

多条启用的颜色规则可以共同作用于日志。若结果不符合预期，逐条停用以缩小范围，检查表达式是否匹配，以及多个规则是否命中了同一段文字。

高亮只是阅读辅助。复制和导出的文本不包含颜色，也不会把标记图标插入日志内容。
