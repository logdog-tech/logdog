## 准备第一份日志

打开 [LogDog 分析器](/)，选择「文件日志」。可以拖入本地文件，也可以点击「选择文件」。首次体验可下载下面的演示日志，其中包含同一次请求从开始到超时的完整过程。

[下载演示日志](/docs-assets/first-investigation.log)

```log
2026-09-30 10:42:01.120 INFO  request=req-1042 accepted GET /api/orders
2026-09-30 10:42:01.146 DEBUG request=req-1042 cache miss
2026-09-30 10:42:04.152 WARN  request=req-1042 upstream slow duration=3006ms
2026-09-30 10:42:06.154 ERROR request=req-1042 timeout duration=5008ms
```

## 定位异常

在搜索框输入下面的表达式，按 Enter 或点击「搜索」。将显示模式设为「只显示搜索」，可以暂时排除标记行的干扰。

```regex
ERROR|WARN
```

结果列表会留下告警与错误。点击超时记录，完整日志视图会定位到相应位置，便于阅读前后的事件。

## 追踪同一次请求

将搜索内容替换为请求标识。比起只看最终错误，这能帮助你还原执行顺序。

```regex
request=req-1042
```

观察缓存未命中、上游变慢和最终超时之间的关系。示例只是演示数据，不能仅凭超时日志就断定根因。

## 标记并导出

点击关键行的行号进行标记。需要导出连续上下文时，在完整日志视图中点击起始行内容，再按住 Shift 点击结束行内容。

在已选区域内右键，选择「导出选中日志」。如果只是少量文本，也可以使用 Ctrl+C 或 Cmd+C 复制已选行。

> 选中超过 1000 行时，行复制会被阻止并提示导出。全选只作用于当前操作的日志视图，不会把两个视图合并。
